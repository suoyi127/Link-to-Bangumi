# 游戏库

游戏库与番剧库、小说库并列。打开游戏库，在顶部填写游戏主程序 EXE 的绝对路径并点击「导入游戏」。程序留在原目录；重复导入同一路径不会创建重复词条。普通主程序名如 Game.exe 会优先用父文件夹名称搜索。

导入后使用设置中的 Bangumi 连接，限定游戏类型搜索，按原名、中文名与别名的唯一匹配自动绑定。获取中文标题、简介、开发商、平台和封面；不确定的结果保留未绑定状态。游戏详情页可查看绑定条目并确认启动，启动工作目录为 EXE 所在目录。

在「资源库 → 游戏资源」整理标题、开发商、简介与启动路径。保存后的人工元数据保留；可自动匹配、刷新刮削、搜索候选或输入 Bangumi 游戏条目 ID 绑定。替换启动路径需要有效且未被其他词条使用的 EXE。

页面每 5 秒以及返回窗口时核对已登记文件。启动文件不可访问时禁用启动；可在资源库确认删除该词条及绑定与封面，磁盘文件保持原样。恢复文件后可以再次导入。

当前支持 Windows 原始 EXE，不支持快捷方式、启动 URI 或命令行参数模板。游戏目录结构保持原样，无需复制或移动安装目录。仅应导入自己信任的游戏程序。

## VNDB 备用来源

Bangumi 初次自动查询没有唯一匹配、未配置或查询失败时，会尝试 [VNDB](https://vndb.org/)。VNDB 主要覆盖视觉小说；按原名、多语言标题与别名唯一匹配，优先采用已存在的简体中文标题，其次繁体标题，没有中文名时保留原名。候选过多或不能唯一确认时，保留未绑定状态供人工选择。

在「资源库 → 游戏资源 → 刮削来源」选择 VNDB，可直接匹配／刷新、搜索候选，或输入 `v4` 这样的 VNDB ID 绑定。Bangumi 与 VNDB ID 分别保留，详情页显示来源链接；当前来源决定元数据和封面，保存过的人工信息继续保留。已绑定的词条按当前来源刷新。

使用 [VNDB Kana 官方 API](https://api.vndb.org/kana)，查询无需账号。封面缓存从官方 CDN 获取，API 使用并发与请求频率限制。简介保存为纯文本，遵循 [VNDB 数据许可](https://vndb.org/d17)并保留来源链接。
