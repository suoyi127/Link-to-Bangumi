# 待整理文件按来源分开展示

待整理页使用“qB 下载”和“外来导入”两个标签。每个标签仅显示对应来源的文件，拥有独立的总数、分页位置和空状态。切换来源时清除当前选中文件、草稿、预览及确认弹窗，避免跨来源执行旧计划；修正、Bangumi 搜索与整理确认流程本身不变。

`GET /api/inbox` 增加可选 `origin=qb_download|external_import`。省略参数时保留原先的混合列表契约。来源筛选在 SQLite 的计数与分页查询中完成，不能先分页再在前端过滤。非法来源返回稳定的 `invalid_origin` 400 错误。前端 API 客户端只为标签页请求传来源参数。

测试覆盖混合与分来源计数/分页、非法来源，以及两个标签独立翻页和切换时预览失效。后端不改数据库结构，不触碰真实 qB 下载目录或导入文件。
