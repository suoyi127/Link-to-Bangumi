# 安装版数据目录

安装版默认将 SQLite 数据库、番剧封面缓存和 WebView2 用户配置统一保存到安装根目录的 Data 子目录。开发启动不改变现有数据位置。

安装器为 Data 授予普通用户修改权限，不扩大整个应用目录的写权限。后端由桌面启动器显式传入 ANIME_VAULT_DATA_DIR，避免工作目录影响数据位置。旧的用户数据不自动搬移或删除；迁移时退出所有应用实例，将旧目录内容复制到空的 Data 目录，保留备份。

实施顺序：修改桌面布局回归测试并确认失败；调整布局、后端启动环境和安装器权限；更新 README 与 Git 忽略规则；运行桌面测试、桌面构建和安装器配置检查。此次不修改文件扫描或刮削逻辑，不重新发布已上传安装包。
