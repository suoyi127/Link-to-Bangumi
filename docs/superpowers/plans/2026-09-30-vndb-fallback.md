# 游戏 VNDB 备用刮削

Bangumi 为首次自动刮削的首选来源。未能唯一匹配、未配置或联网失败时尝试 VNDB Kana /vn。已有绑定按当前来源刷新，人工在游戏资源选择 Bangumi 或 VNDB。两站点 ID 独立保存，当前元数据和封面标明来源；人工元数据保留。

VNDB 主要覆盖视觉小说。无需账号查询；优先简体中文标题，其次繁体中文，原名与多语言名称和别名用于唯一匹配。多候选或分页未完整时请求人工选择。简介转为纯文本，封面仅允许官方 t.vndb.org/cv 路径，尺寸受限并检查图片格式。API 有并发和窗口限流。
