# 游戏库实现计划

目标：与番剧库、小说库并列的游戏库，通过本机 EXE 原位导入，自动获取 Bangumi 游戏标题、简介、开发商和封面。导入入口位于游戏库，元数据与路径编辑位于资源库的游戏资源页。

设计：独立 game_resource 表，通过第 9 版迁移建立。GameService 管理路径与记录；GameBangumiService 使用 type=4 搜索、标题与别名唯一匹配、人工绑定和已有封面缓存能力。GameController 提供严格字段校验的本机接口。启动时使用程序目录作为工作目录，导入和刮削不执行程序。

- [x] 后端临时目录测试：重复导入、可访问状态、编辑保留、不可访问记录删除、启动参数与工作目录。
- [x] 实现数据库迁移、服务、游戏过滤搜索和安全启动。
- [x] 实现游戏库、直接导入、游戏资源编辑及手动绑定。
- [x] 构建、后端 30 项测试、相关前端 5 项测试、lint、前端生产构建通过；实际游戏搜索返回 CLANNAD 条目，运行版本已更新。

整理仅修改数据库信息，保持游戏目录结构。游戏必须为原始 EXE 文件，暂不支持快捷方式、URI 和参数模板。自动匹配只接受唯一标题或别名匹配；用户编辑的标题与简介不被后续刮削覆盖。
