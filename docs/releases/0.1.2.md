# Anime Vault V0.1.2

- 改进番剧刮削：兼容罗马拼音、别名、空格及常见发布标题格式。
- 使用 Bangumi 分集表将可靠的累计集数映射到季度内集数，保留原始值及人工修改。
- 番剧重新绑定遇到已有词条时提供合并预览与确认，保留已有资料、转移媒体及别名，不移动实际文件。
- 优化 Bangumi 请求排队、缓存和限流提示，人工操作优先。
- 新订阅默认开启正则与智能集数过滤，每集首个符合条件版本优先；立即下载、零天间隔，排除 REPACK。
- 新规则根据可靠历史及当前任务补齐集数记录，不再批量标记 RSS 已读；同源启用规则防重复创建。
- 提供禁用的新订阅规则导入模板。

安装程序：Setup.exe（Windows x64）。

安装包包含 VC++ 运行库与 WebView2 引导程序，WebView2 未安装时需要联网获取运行时。
现有 qB 规则不会自动批量迁移；新版默认策略用于新增订阅。
