# 0.1.0

Windows 安装版：下载本页附件 `Setup.exe`，安装后从开始菜单打开 Anime Vault。首次使用请在设置页配置 Bangumi、qB Web UI 和自己的下载目录。

## 本次更新

- 番剧库支持每周排期、中文标题与别名匹配、封面刮削和播放器选择。
- 资源库区分 qB 下载、外来导入和文件夹导入；导入已有文件夹不复制原文件。
- 新增小说库、阅读器配置、文件与文件夹导入、Bangumi 刮削和不可访问资源的手动清理。
- 新增游戏库：导入游戏 EXE、整理资源、启动游戏；支持 Bangumi 刮削及 VNDB 备用来源。
- 优化页面布局、封面尺寸和折叠面板；完善启动说明与独立 PowerShell 命令文档。

## 使用说明

- 应用内部版本号、GitHub 标签与发布名称均为 `0.1.0`。
- 更新后的 `Setup.exe` 将数据库、封面和 WebView2 用户缓存统一保存在 `<安装目录>\Data`，媒体库和外来导入目录也跟随安装位置。安装器配置 Data 写入权限，卸载不主动清理数据。
- 本次安装包基于提交 `facd2b823e593edb79fa6ca5d10bf59b97e5c901` 重新构建，保留原 `0.1.0` 标签历史。旧包改名为 `Setup-legacy-user-data.exe`，仅供回退；正常使用请下载 `Setup.exe`。
- 升级前退出所有应用实例并备份 `%LOCALAPPDATA%\AnimeVault`。需要保留旧数据时，将旧目录内容复制到空的 `<安装目录>\Data`；不自动迁移，不覆盖已有数据库，详见 README 的旧版数据迁移说明。
- 安装包尚未签名，缺少运行库时安装过程需要联网。安装与升级前建议备份现有数据库。
- 扫描和整理不会代替 qB 下载完成确认；文件整理仍需先预览并确认。
