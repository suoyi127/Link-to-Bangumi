# V0.1.1

Windows 安装版：下载附件 Setup.exe，安装后从开始菜单打开 Anime Vault。

## 更新内容

- qB 每 10 秒检测已下载资源并自动扫描，排除下载中和校验中的任务。
- 自动绑定成功的文件不再出现在待整理列表。
- 番剧详情支持修改标题、季数、封面以及单个文件的集数信息。
- 全部番剧按导入月份分组展示，支持月份正序与倒序，保留分页。
- 每周排期缩小封面，按星期几独立分行，同一天内容自动换行。
- MIKAN 订阅列表支持折叠，摘要始终可见。

## 安装说明

- 升级前退出 Anime Vault 并备份安装目录中的 Data 文件夹。
- 安装目录和应用数据规则沿用 0.1.0；卸载不会主动清理 Data。
- 安装包未签名；缺少 VC++ 或 WebView2 运行库时，安装过程需要联网。
