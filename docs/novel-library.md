# 小说库使用方法

## 导入与阅读

1. 打开 **设置 → 小说阅读与导入**。
2. 默认选择“系统默认关联”；如果已有独立阅读器，选择“自定义阅读器”并填写其 EXE 的绝对路径。阅读器需要能够接收文件路径参数，实际支持格式取决于阅读器。
3. 填写本机小说文件夹或单个文件的绝对路径，点击“导入小说资源”。当前支持 EPUB、TXT、PDF；文件夹会递归扫描。
4. 打开与番剧库并列的 **小说库**，点击作品查看卷文件，再点击“阅读”。这是调用本机阅读器，不是网页内阅读。

导入只记录原位置，不复制、移动或删除原文件。路径从系统文件管理器复制粘贴；当前没有原生文件选择弹窗。小说列表会核对已有文件是否可访问，页面每 5 秒及返回窗口时刷新；缺失文件禁用阅读，恢复原位后自动恢复。作品、卷和 Bangumi 记录保留。新增文件仍需在设置中重新扫描来源。

## 作品与卷

明确的末尾卷标（例如 `Vol.01`、`第01卷`、`(02)`、`[03]`）会用于聚合；原文件名作为卷标题保留，不实际重命名。

资源库上方选择 **小说资源**，可编辑作品名、作者、简介；每个卷可以修改显示标题、改归属到已有作品。不同拼写或别名可能形成两个作品，需要在这里调整卷归属。人工保存的元数据不会被后续自动刮削覆盖。

## Bangumi 刮削

- 与番剧共用设置页中的 Bangumi User-Agent；不需要个人 Token。
- 导入后自动查询书籍，读取中文名、作者、简介和封面；需要等待网络请求结束后刷新小说库。
- 自动绑定仅接受小说分类明确、原名／中文名／别名唯一精确匹配的结果；多卷作品还要求结果是系列条目。
- 未匹配、同名结果过多或网络失败时，本地导入仍有效。在资源库选中作品，点击“自动匹配／刷新刮削”重试，或搜索书籍后人工核对绑定。
- “绑定对象”可以选整部作品或具体卷，二者独立保存。候选会显示系列／单卷分类，也可直接填写 Bangumi 正整数条目 ID。
- 明确漫画或动画条目不接受小说绑定；分类未知的书籍只能人工确认。没有中文名时保留原名，不通过翻译猜测正式名称。
- 封面存本地数据库，网络断开后已有封面仍可显示。封面失败不撤销已成功的条目绑定。

本版本不提供内置 EPUB 排版、阅读进度同步或自动下载小说。
# 手动清理不可访问词条

在「资源库 → 小说资源」中，只有作品的全部文件均不可访问（包括没有卷文件的空词条）时，才显示「删除词条」。确认弹窗会列出作品名并说明影响范围。

删除仅清理作品、卷记录及其 Bangumi 绑定与封面，不删除磁盘文件或导入来源。后端在执行时再次核对文件状态；任一文件已恢复可访问时拒绝删除。重新扫描仍存在的文件可再次导入，但不会恢复已删除的人工元数据。
