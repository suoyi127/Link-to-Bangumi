**LinkToBangumi**
-本项目旨在优化本地ACG资源管理，主要对个人常用的游戏（尤其是gal，怀旧游戏的移植版等），番
剧，轻小说资源进行管理。
-下面介绍目前对几个模块的实现方案
**游戏部分**
-游戏只实现了使用.exe文件地址的导入，，可以在资源库中进行游戏名绑定（根据游戏目录自动匹配
的游戏名和刮削源经常不匹配），当前游戏主要通过Bangumi进行刮削，但鉴于Bangumi下掉了r18游戏
的词条，所以补充了VNDB作为刮削源，如果后面还有明显缺口再补充其他刮削源。

**番剧部分**
-番剧部分除了文件夹导入和文件导入还支持qb配置实现自动化追番（qb内的配置网上已经有不少教程，
现在还在用bt下番的情况也不是很普遍，就不做过多介绍）
-另外通过Bangumi的排期表接口获取每日更新情况，可以按照排期表查看番剧。
-本项目没有内置播放器，需要自行使用自己喜欢的播放器
