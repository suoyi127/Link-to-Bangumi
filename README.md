# LinkToBangumi

LinkToBangumi 旨在优化本地 ACG 资源管理，主要用于管理个人常用的游戏、番剧和轻小说资源。其中，游戏部分重点面向 Galgame、怀旧游戏移植版等。

## 游戏

### 资源导入与名称绑定

目前支持通过 `.exe` 文件路径导入游戏。

由于根据游戏目录自动识别的名称可能与刮削源中的名称不一致，可以在资源库中手动绑定游戏名称，提高匹配准确度。

### 元数据刮削

游戏目前主要通过 **Bangumi** 获取元数据。考虑到 Bangumi 部分 R18 游戏词条的缺失，项目补充了 **VNDB** 作为刮削源。后续如有明显的覆盖缺口，将考虑接入其他来源。

## 番剧

### 资源导入与自动追番

支持通过以下方式管理番剧资源：

- **文件夹导入**：批量导入本地番剧资源。
- **文件导入**：导入单个视频文件。
- **自动追番**：配合 qBittorrent 配置，实现自动化追番。

qBittorrent 的相关配置已有较多教程，本文不再展开介绍。

### 每日排期

通过 **Bangumi 排期表接口**获取每日更新信息，支持按排期表查看番剧。

### 播放方式

项目不内置播放器，需自行配置喜欢的播放器。

## 轻小说

轻小说的资源管理方式与游戏、番剧基本一致，需额外配置阅读器，此处不再重复介绍。
